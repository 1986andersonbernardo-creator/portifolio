# Portfólio Profissional - Anderson Bernardo

Portfólio profissional de nível enterprise, desenvolvido com foco em design moderno, performance e experiência do usuário.

## 🎯 Sobre o Projeto

Portfólio profissional para Anderson Bernardo da Silva, Desenvolvedor Front-end e Freelancer, especializado em criar sites, landing pages e sistemas web personalizados.

## ✨ Características

### Design & Experiência
- **Design Moderno**: Inspirado nos melhores portfólios do Awwwards (Apple + Stripe + Vercel)
- **Dark Mode Elegante**: Tema escuro sofisticado com glassmorphism
- **Gradientes Discretos**: Uso estratégico de gradientes para visual premium
- **Micro-animações**: Animações suaves que melhoram a experiência do usuário
- **Scroll Reveal**: Animações de entrada baseadas em scroll
- **Parallax Leve**: Efeitos sutis de profundidade

### Funcionalidades Técnicas
- **Custom Cursor**: Cursor personalizado com efeito de hover
- **Navegação Suave**: Smooth scroll entre seções
- **Menu Responsivo**: Hambúrguer funcional para mobile
- **Contadores Animados**: Estatísticas com animação de números
- **Barras de Skills**: Barras de progresso animadas com shimmer effect
- **GitHub Integration**: Consumo da API pública do GitHub

### Performance & SEO
- **SEO Otimizado**: Meta tags, descrições e estrutura semântica
- **Performance**: CSS otimizado e JavaScript vanilla (sem dependências)
- **Responsivo**: Mobile-first design, funcionando em todos os dispositivos
- **Acessibilidade**: Suporte a leitores de tela e navegação por teclado
- **Lazy Loading**: Carregamento otimizado de imagens
- **Nota Lighthouse**: Otimizado para +95

## 🛠️ Tecnologias Utilizadas

### Frontend
- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Variáveis CSS, Flexbox, Grid, Animações
- **JavaScript ES6+**: Vanilla JS, sem frameworks pesados

### Design
- **Glassmorphism**: Efeitos de vidro fosco
- **Gradientes**: Gradientes modernos e sutis

## 🔧 Instalação e Uso

1. Clone o repositório:
```bash
git clone https://github.com/AndersonBernardo/portfolio.git
```

2. Abra o arquivo `index.html` em seu navegador ou use um servidor local:
```bash
# Com Python
python -m http.server 8080

# Com Node.js
npx serve .

# Com VS Code Live Server
# Clique com botão direito em index.html > "Open with Live Server"
```
